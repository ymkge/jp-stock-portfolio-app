## 概要

ユーザーが管理する国内株式、米国株式、投資信託のポートフォリオに基づき、株価や財務指標、配当履歴などをYahoo!ファイナンスから取得し、Webページに一覧表示するシングルページアプリケーション（SPA）です。
各指標が割安か割高かを視覚的に判断するためのサポート機能も搭載しています。

## 主な機能

- **AI投資方針適合診断 & スマートキャッシュ [新機能 #237 #241 #245 #246 #248 #249 #250]**:
    - **LLM自動適合診断**: ユーザー自身が定義した独自の「投資方針プロンプト」に基づき、Google Gemini AIがポートフォリオおよび個別の銘柄が方針に合致しているか（適合 Fit / ボーダー Borderline / 見送り Avoid）を多角的に自動診断・要約します。
    - **最重要カードの視覚的強調デザイン [新機能 #249]**: 意思決定の核となる「📌 総合判定サマリー（結論）」および「💡 本システムでの立ち回りアドバイス（アクション）」をエメラルドグリーン枠およびアンバーゴールド枠で色分け強調。モーダルを開いた瞬間に視線が直感誘導されるアクセシビリティ（WCAG AAA適合）を確立。
    - **ダークモード文字視認性の完全修復 [バグ修正 #250]**: 親コンテナ `.llm-card` の不透明ダーク背景化（`#111827`）および上部タグ（確信度・Model表示・配当利回り帯）と全カードの文字色を純白〜高輝度ライトカラーへ修復。黒背景の上で一切かすれることなく、文字が鮮明にくっきり浮かび上がります。
    - **銘柄毎に先月比での資産増減ランキングTOP20表示機能 [#270 #274]**:
    - **前月末日比の資産変動を可視化 (TOP20拡大)**: カレンダー上の前月末日時点のスナップショット評価額と現在の評価額を口座横断（新NISA、特定口座等）で照合し、先月比・当日比での資産増加 TOP20 / 資産減少 TOP20 をモーダル表示。当月買い増し銘柄による上位占有を防ぎ、純粋な株価上昇によって資産増加に大きく寄与したパフォーマンス上位銘柄の視認性を劇的に向上。
    - **カレンダー月ベース (方式A) の運用判断**: 毎月1日にベースラインがリセットされ、「当月に入ってからどの銘柄が自分の資産を牽引したか／押し目買いのチャンスか」を月を通じてブレずに把握可能。
    - **当月新規購入 ✕ 売却済銘柄の自動判別**: 当月新たにポートフォリオへ追加された銘柄（`【新規】` バッジ）や売却完了銘柄（`【売却済】` バッジ）も漏れなく集計・表示。
    - **株式分割銘柄の自動評価額補正 (Self-Healing Split Correction) ✕ 本番DB物理隔離・テスト汚染自動防御 [#271 #284]**: 株式分割の適用過渡期（例: 三井住友トラスト8309 1:4分割等）において評価額を自動補正。さらにテスト実行時の自動分割検知による本番DBへの誤書き込みを全テーブルでクリーンアップ消去し、`conftest.py` による自動物理隔離フィクスチャ（三重防衛構造）を導入。テスト実行時でも本番DB (`portfolio_history.db`) への混入を100%物理遮断。
    - **当月中買付株数 ✕ 概算投資額の可視化 [#272]**: 当月中に追加購入（新規・買い増し）した銘柄について、銘柄名の下に `🛒 当月買付: +20株 (約40,000円)` のサブテキストタグを表示。「株価上昇による資産増加」と「追加入金・買い増しによる資産拡大」を直感的に識別可能。金額隠しマスク (`isAmountVisible`) とも完全連動。
    - **保有銘柄の売り時・利確検討（配当10年/15年/20年/30年分達成）の可視化 ✕ 口座横断合算 ✕ ツールチップ統合 ✕ 配当利回り表示 ✕ AI利確・銘柄入替診断 (Gemini AI: 業種将来性・日本政府国策投資・累進配当・DOE考慮) ✕ モーダル2回目以降再表示安定化 ✕ エラー防衛・白紙表示防止 ✕ 高視認性再診断ボタン [#273 #275 #276 #277 #278 #280 #281 #282 #283 #285 #286 #287]**: 保有銘柄の含み益が将来の年間予定配当金の何年分に到達しているかを自動計算し、10年分（`💰 10年分`）〜30年分（`💎 30年分`）の4段階で利確・銘柄入替検討の好機を可視化。複数口座の集約・直近「配当利回り（%）」表示に加え、**Gemini AI による「🤖 AI利確診断」機能**を追加。配当利回りが低下した高騰銘柄であっても、**所属業種の将来性や日本政府の国策投資、さらにはDOE（株主資本配当率）・累進配当・連続増配などの強固な株主還元姿勢**をAIが多角的に評価し、減配リスクの極めて低い優良株に対する安易な全額利確を抑制して「継続保有」や「一部利確（投入元本回収・恩株化）」を優先判定。診断結果モーダルに「🚀 業種将来性・国策・成長力評価」専用カードを追加。通信エラーや一時的なAPI制限発生時でもモーダル内が白紙化せず具体的にエラー警告と「🔄 再診断」ボタンを表示する多重防衛構造（`!data.action` 安全ガード）を確立。フッターの「🔄 再診断」ボタンを専用ピル型クラス（`.pt-ai-retry-btn`）へ刷新し、ホワイトモード・ダークモード双方で高コントラスト（WCAG AAA適合）かつ鮮明に文字が見えるスタイリッシュデザインを達成。ダイアログモーダルを1回閉じた後の2回目以降の再オープン時でも表示スタイル (`display: flex`) を確実に復元・連動。既存適合診断との完全分離キャッシュ（12時間有効・0.1秒高速復元）＆全テーマ完全対応。
- **高精度AI適合度診断 (Gemini API) ✕ ファンダメンタルズ直結連動 [新機能 #245]**: 1株当たり利益(EPS)や時価総額等の最新業績指標をAIへ提示。結果画面に専用カード「📊 直近の業績動向と収益力」を追加し、企業の稼ぐ力や配当維持力を考慮した高度な判定を行います。
    - **材料出尽くし・マクロ分析の連携 [新機能 #246]**: 米国市況ショックや地政学・災害等のマクロ環境ニュースと定量的オシレーターをAIが解析。「📉 材料出尽くし・反転シグナル分析」カードを提示します。
    - **2列コンパクトレイアウト & ファーストVIEW完全収容 [新機能 #248]**: レポートカードを左右2列 (`1fr 1fr`) に配置転換。高さ制限（`max-height: 88vh`）と内部スクロールにより、スクロール不要で全主要カードがファーストVIEW内に収まるスマートなUIへ刷新しました。
    - **スマートキャッシュ (0.1秒高速化 & レート制限回避)**: 銘柄ごとの診断結果をメモリ内でスマートキャッシュ（有効期限 12時間 / 最大200銘柄 LRU管理）し、2回目以降の再アクセスは Gemini API を叩かず **0.1秒で即座に復元表示** します。
    - **UIバッジ & 強制再診断**: キャッシュ表示時は「⚡ キャッシュ表示 (HH:mm)」バッジを表示。最新株価でやり直したい場合はモーダル内の「🔄 再診断」ボタンで即時再実行が可能です。投資方針プロンプトやモデル変更時は全キャッシュが自動パージされます。
    - **高精度データ伝播**: バックエンドの配当利回り（`yield`）、ROE、DOE、配当性向を型安全にプロンプトへ組み込み、インカムゲイン銘柄の誤判定を完全に防ぎます。
- **材料出尽くし感による変動予測機能 [新機能 #246]**:

    - コードの形式から資産タイプ（国内株/米国株/投資信託）を自動で判別する。
- **資産の削除**
    - ポートフォリオから特定の資産を選択して一括で削除する。
- **資産情報表示**
    - 資産タイプごとにタブで表示を切り替える。
    - 各資産の最新情報を一覧で表示する（株価、前日比、時価総額など）。
    - 一覧の各項目でソート（並び替え）が可能。
    - 銘柄コードや名称で表示内容をフィルタリングする。
- **保有状況の管理**
    - 資産ごとに、複数の口座（特定口座, 一般口座, 新NISA, 旧NISA）の保有情報を登録・更新・削除できる。
    - 保有情報には「取得単価」と「数量」を記録する。
- **データ更新**
    - 「全件更新」ボタンで、ポートフォリオ内の全資産の情報を最新化する（クールダウン機能付き）。
- **CSVエクスポート**
    - 現在表示しているポートフォリオの一覧をCSVファイルとしてダウンロードする。

### 2. ポートフォリオ分析機能
- **サマリー表示**
    - ポートフォリオ全体の評価額、投資額、損益、損益率、年間配当合計などを表示する。
    - 金額表示のON/OFFを切り替えることができる。
- **グラフ表示**
    - 保有資産の構成比を円グラフで可視化する（業種別、口座種別、証券会社別、国別、配当構成）。
    - **ポートフォリオ特性（レーダーチャート）**: 「割安性」「収益性」「インカム」「クオリティ」「モメンタム」「分散度」「安全性」の7つの軸で資産全体のバランスを可視化。
    - **月別配当分布 (予測)**: 日本株・米国株の支払いパターンに基づき、将来の配当収入を月別に棒グラフで可視化。
- **保有銘柄一覧**
    - 全ての保有資産の詳細な情報を一覧で表示する（評価額、損益、損益率など）。
    - 銘柄名、業種、口座種別、証券会社、**シグナル**でフィルタリングが可能。
- **分析結果のCSVエクスポート**
    - 保有銘柄一覧をCSVファイルとしてダウンロードする。

### 3. データ取得・加工機能
- **スクレイピング（安定化・高速化対応済み）**
    - Yahoo!ファイナンスから以下の情報を取得する。
        - **国内株式**: 株価、企業情報（業種、決算月）、財務指標（PER, PBR, ROE, EPS）、配当情報（利回り, 過去配当履歴）。
        - **米国株式**: 株価、市場情報、財務指標（PER, EPS）、決算月、および配当情報（配当利回り、配当性向、年間配当金）。
        - **投資信託**: 基準価額、純資産総額、信託報酬。
    - **安定化対策**: `requests.Session` による接続維持、同時実行数の制限、銘柄内待機時間を導入し、アクセス制限（500エラー）を回避します。
    - **高速化対策**: キャッシュ存在時の待機スキップロジックにより、2回目以降の表示を高速化します。
- **スコアリング（国内株式のみ）**
    - PER, PBR, ROE, 配当利回り, 連続増配年数などの指標に基づき、独自の評価スコアを算出する。
- **注目シグナル判定**
    - テクニカル指標（RSI, RCI, フィボナッチ, 25日線等）とファンダメンタルズスコアを組み合わせ、買い場（**中期GC/25日線突破**等）や過熱感（**中期DC/25日線割れ**等）を判定する。

## セットアップと実行方法

1. **リポジトリをクローンします。**
   ```bash
   git clone https://github.com/your-username/jp-stock-portfolio-app.git
   cd jp-stock-portfolio-app
   ```

2. **必要なPythonライブラリをインストールします。**
   ```bash
   pip install fastapi uvicorn python-multipart requests jinja2 beautifulsoup4 cachetools pytest pytest-mock
   ```

3. **FastAPI開発サーバーを起動します。**
   ```bash
   uvicorn app:app --reload
   ```

4. **ブラウザでアクセスします。**
   Webブラウザを開き、 `http://127.0.0.1:8000` にアクセスしてください。
